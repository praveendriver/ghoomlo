# Ghoomlo

An India-first consumer travel-planning product in discovery and prototype development.

## Project contents

- `PRODUCT_BRIEF.md` — product goals, audience, and principles.
- `LAUNCH_PLAN.md` — staged validation and launch plan.
- `DISCOVERY_NOTES.md` — traveler discovery findings so far.
- `FRAMEWORK_REVIEW.md` — product and UX framework review.
- `prototype/index.html` — interactive concept prototype. Its itinerary prices, provider offers, and travel content are simulated.
- `travel-agent-bundle/app/` — the imported travel-planning harness, scripts, skills, and trip pages.

## Open the prototype

Open `prototype/index.html` in a browser. It runs locally and does not need an API key.

## Run the imported application

Follow `travel-agent-bundle/app/README.md` and `travel-agent-bundle/app/API_SETUP.md` for the harness setup. Credentials and local caches are intentionally excluded from Git.
