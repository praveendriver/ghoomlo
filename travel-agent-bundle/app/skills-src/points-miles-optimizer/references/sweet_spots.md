## Marriott Bonvoy → Airlines

- 3:1 base ratio to 40+ airline programs.
- Transfer **60,000 Marriott points** → **25,000 airline miles** (3:1 + 5K bonus per 60K block). Strong if you're sitting on Marriott points.
- Best targets: Alaska, Avios (BA/Qatar), United, Singapore KrisFlyer.

## Cabin-Specific Heuristics from India

- **India ↔ Europe biz**: target 80-100K miles one-way via Qatar Avios or KrisFlyer. Cash at ₹1.5-2.5L economy = ~₹2-4/mile.
- **India ↔ US biz**: target 80-120K miles one-way via partner award. Cash at ₹3-5L = ₹3-5/mile (high value).
- **India domestic**: rarely worth points unless last-minute. Use cash, earn miles.
- **India ↔ SE Asia eco**: only worth points if surcharge-free; cash often beats it.

## Always-Verify Items

- Sustained availability windows (especially family of 4 — 4 award seats on the same flight is often the binding constraint).
- Real-time YQ surcharges per program (use the program's redemption calculator — never an old blog).
- Open-jaw / stopover rules — vary widely.
